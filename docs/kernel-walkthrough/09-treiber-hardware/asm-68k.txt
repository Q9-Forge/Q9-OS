Registerkonvention (aus dem Code erschlossen, OS-9/68K-Treiber-Standard):
  A2 = Zeiger auf Treiber-Static-Storage; (0,A2) = I/O-Basisadresse -> A3
  A1 = Zeiger auf Path-Descriptor/Device-Tabelleneintrag
  A5 = Zeiger auf Datenpuffer des Aufrufers
  D2 = Blocknummer (LBA)
