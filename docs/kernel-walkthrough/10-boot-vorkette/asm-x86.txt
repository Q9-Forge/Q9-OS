; baut ueber mehrere PIC-Trampoline (CALL $+5/POP EDI/LEA, das bereits in
; frueheren Themen als Compiler-/Toolchain-Artefakt dokumentierte Muster)
; drei feste Modul-Adressen zusammen (EDI+0x1e1, EDI+0x1cc, EDI+0x1d8) und
; schreibt sie in Kernel-Globals-relative Felder:
0000014a: MOV ECX,dword ptr [EBP + -0x8]

0000015f: MOV ECX,dword ptr [EBP + -0x8]
00000162: MOV dword ptr [ECX + 0xac4],EAX   ; Handler-Adresse 2
00000183: MOV ECX,dword ptr [EBP + -0x8]
00000186: MOV dword ptr [ECX + 0xac8],EAX   ; Handler-Adresse 3
00000171: MOV dword ptr [EAX + 0xad0],ECX   ; (vierter Wert, EBX-basiert)
;
; ==> installiert mehrere feste Adressen in Kernel-Globals-Felder
;     (+0xac0/+0xac4/+0xac8/+0xad0) -- konzeptionell dieselbe Art
;     Operation wie die in Thema 06 gefundenen PC-relativen Konstanten-
;     Installationen bei +0xa0c..+0xa98, nur mit anderen Offsets und in
;     einem EIGENEN, bisher unbekannten Modul statt im Kernel selbst.
;     Vermutlich ein frueher Bootstrap-Schritt VOR oder WAEHREND
;     Q9X_kernel_globals_init (Thema 01) -- nicht abschliessend verifiziert.
